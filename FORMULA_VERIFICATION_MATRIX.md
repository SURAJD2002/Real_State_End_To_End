## 1. Scope & Methodology

This matrix audits **every mathematical equation, geometric invariant, spatial formulation, optimization domain, and financial calculation** implemented in the Planwise Enterprise codebase. Each formula is verified against:
1. The **active implementation in Python / TypeScript source files**
2. The **underlying physical / statutory / engineering standards** (WGS84, IS 1200, NBC 2016, Mumbai DCPR 2034, BBMP Bye-Laws 2026, OR-Tools CP-SAT)
3. The **claims published in the Forensic Technical Master Report (PDF)**
4. The **automated regression and unit test suite** (`tests/test_*.py`)

### Verdict Classifications:
- **`VERIFIED CORRECT`**: The formula in the source code is mathematically sound, dimensionally consistent, has well-defined boundary handling, and is backed by automated tests.
- **`CORRECT BUT INCOMPLETE ASSUMPTIONS`**: The formula is mathematically correct for its declared domain, but relies on domain assumptions (e.g. orthogonal boundary buffer, single-flight stair model) that are bounded in scope.
- **`DOCUMENTATION ERROR`**: The implementation in source code is correct and tested, but the forensic PDF report misquoted the formula, stated contradictory units (e.g. "radians" while multiplying by $\pi/180$), or documented textbook equations rather than the actual code logic.
- **`IMPLEMENTATION ERROR`**: The code implementation itself contains a mathematical flaw, unit mismatch, or incorrect logic.
- **`UNVERIFIED`**: The formula lacks sufficient test coverage or relies on unverified external assumptions.
